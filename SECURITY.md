# Seguridad

Reporta las vulnerabilidades mediante un aviso privado de seguridad de GitHub en este repositorio. Incluye una descripción que se pueda reproducir y el impacto, pero no adjuntes claves de API, comprobantes, números de cuenta ni datos de clientes.

No uses issues públicos para vulnerabilidades sin corregir. Si una clave de API aparece en registros o en un reporte, revócala antes de compartir cualquier evidencia.
